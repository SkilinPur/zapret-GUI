# Changelog

Все заметные изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.0.7] — 2026-08-11

### Исправлено
- Баг «Несуществующая стратегия!» для файлов с пробелами и скобками в названии (например `general (ALT2).bat`): проверка стратегии переписана с регулярных выражений на сравнение строк — метасимволы в имени больше не ломают поиск.
- Переименование стратегий (`rename_bat.sh`) теперь использует абсолютный путь по умолчанию и не может «молча» пропустить переименование при запуске не из корня проекта.

## [1.0.6] — 2026-08-11

### Добавлено
- Во вкладке «Обновление» теперь показывается CHANGELOG.md: выпадающий список версий и описание изменений каждой версии прямо в программе. Новая доступная версия добавляется в список со своими заметками релиза.

## [1.0.5] — 2026-08-11

### Добавлено
- Цветные логи во встроенных «терминалах» всех вкладок: команды — голубые, ошибки — красные, успешные действия — зелёные, заголовки — оранжевые.

### Исправлено
- Убран мигающий курсор в шапке окна — подзаголовок больше не «прыгает» из-за мигания.

## [1.0.4] — 2026-08-11

### Добавлено
- Тестовая версия для проверки функции обновления программы (обнаружение новой версии, окно обновления, `git pull`, перезапуск).

## [1.0.3] — 2026-08-11

### Исправлено
- Проверка обновлений теперь работает даже когда GitHub API недоступен или профиль скрыт: добавлен запасной способ определения последней версии через `git ls-remote --tags`. Раньше при 404 от GitHub API показывалась ошибка «не удалось проверить обновления».
- Добавлен CHANGELOG.md с описанием изменений.

## [1.0.2] — 2026-08-11

### Добавлено
- Вкладка «Обновление»: текущая и доступная версия, описание изменений, кнопка «Обновить».
- Автопроверка обновлений при запуске: если есть новая версия — окно с версией и списком изменений.
- Обновление в один клик: `git pull` + предложение перезапустить приложение.

## [1.0.1] — 2026-08-11

### Исправлено
- Баг: список стратегий во вкладке «Конфигурация» не обновлялся после скачивания/обновления стратегий во вкладке «Стратегии». Теперь список перечитывается при каждом открытии вкладки.

## [1.0.0] — 2026-08-11

### Добавлено
- Первый релиз GUI (PySide6) поверх zapret-discord-youtube-linux.
- Вкладки: Как пользоваться, Статус, Конфигурация, Стратегии, Сервис, Автоподбор, Права, Авторство.
- Тема: гибрид Discord + хакинг в красно-чёрных тонах.
- Интеграция с `service.sh` (команда `gui` и пункт меню).
